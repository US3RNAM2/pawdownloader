PawDownloader

PawDownloader is a personal desktop download tool, used only by its owner on their own computer.

When a Google Drive file shared with a link cannot be downloaded because its download limit was reached, PawDownloader can (if the user turns this on and signs in) make a temporary copy of that file in the user's own Google Drive, download the copy to the user's own computer, and delete the copy right away.

PawDownloader 는 개인이 자기 컴퓨터에서만 쓰는 다운로드 도구입니다. Google Drive 공유 파일이 다운로드 한도로 막히면, 사용자가 켜 두고 로그인한 경우에만 그 파일의 사본을 사용자 본인의 드라이브에 잠깐 만들어 받고 바로 지웁니다.
