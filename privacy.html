PawDownloader Privacy Policy

Last updated: 2026-11-25

What the app accesses

With the user's permission (Google sign-in), PawDownloader uses the Google Drive API only to:

  • read the name and size of a Drive file the user is trying to download,
  • create a temporary copy of that file in a folder named "PawDownloader 임시 사본 (자동 삭제)" in the user's own Drive,
  • download that copy to the user's own computer, and
  • permanently delete the copy (and any copies left over from an interrupted run in that folder).

It does not read, change or delete any other file in the user's Drive.

Where data is kept

The sign-in token and downloaded files are stored only on the user's own computer. No data is sent to the developer or to any third party. There is no server, no advertising and no analytics.

Google API Services User Data Policy

PawDownloader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Use "Log out" in the app's settings, or remove the app at https://myaccount.google.com/permissions. Deleting the app's data folder removes everything it stored on the computer.
